Start a **background agent** to do the research, so you keep working while it reads.

Its job:

1. Investigate the question against **primary sources** — official docs, source code, specs, first-party APIs — and not a second-hand write-up of them. Follow every claim back to the source that owns it.
2. Write the findings to a single Markdown file. Cite the source of each claim.
3. Save the file where the repo already keeps such notes. Match the existing convention. If there is none, put it somewhere sensible and say where.
