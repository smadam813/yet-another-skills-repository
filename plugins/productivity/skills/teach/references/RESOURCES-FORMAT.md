# RESOURCES.md Format

`RESOURCES.md` is the curated set of trusted sources for this topic. Draw the knowledge in your lessons from here, not from what you already think you know. Wisdom comes from the communities this file lists.

## Structure

```md
# {Topic} Resources

## Knowledge

- [Book: _The Science and Practice of Strength Training_ by Zatsiorsky & Kraemer](https://example.com)
  Foundational text on programming and adaptation. Use for: anything to do with periodization, recovery, intensity zones.
- [Article: "How Much Should I Train?" by Greg Nuckols (Stronger By Science)](https://example.com)
  Evidence-based review of volume landmarks. Use for: weekly set targets per muscle group.

## Wisdom (Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  High-signal subreddit, moderated against bro-science. Use for: program critique, plateau troubleshooting.
- Local: Tuesday strength class at {gym name}
  Use for: real-time coaching feedback on lifts.
```

## Rules

- **High-trust only.** Prefer primary sources, recognized experts, peer-reviewed work, and communities with strong moderation. If a resource is marketing dressed as education, leave it out.
- **Annotate every entry.** A bare link is useless in three months. Add one line: what it covers, and when to reach for it.
- **Group by Knowledge / Wisdom.** This mirrors the philosophy in [SKILL.md](../SKILL.md). A resource may appear in only one group.
- **Record every gap.** When no good resource covers an area the mission needs, write a `## Gaps` section that lists what is missing. This drives future searches.
- **Prune ruthlessly.** Remove a resource that turned out to be wrong, shallow, or off-mission. Do not bury it. Five sharp sources beat thirty mediocre ones.
- **Record community preferences.** If the user has opted out of joining communities, note it here so that future sessions stop proposing them.
