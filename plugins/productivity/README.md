# productivity

Skills for everyday productivity.

## Skills

- [`grill-me`](skills/grill-me/SKILL.md) — sharpen a plan or a design in a relentless
  interview.
- [`grilling`](skills/grilling/SKILL.md) — stress-test a plan, a decision, or an idea.
- [`handoff`](skills/handoff/SKILL.md) — compact the current conversation into a handoff
  document for another agent.
- [`orwell-writing`](skills/orwell-writing/SKILL.md) — apply Orwell's six rules and
  ASD-STE100 plain English discipline to written prose.
- [`teach`](skills/teach/SKILL.md) — teach a new skill or concept in the workspace.
- [`to-questionnaire`](skills/to-questionnaire/SKILL.md) — turn a decision you cannot answer
  alone into a questionnaire for someone else.
- [`wait-what`](skills/wait-what/SKILL.md) — stop and re-pitch an unclear message.
- [`writing-for-agents`](skills/writing-for-agents/SKILL.md) — write documents that agents
  read: skills, `AGENTS.md`, and `CLAUDE.md`.
